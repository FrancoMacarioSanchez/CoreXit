Cada SaaS (GestionAR, StockeAR, Turnos, …) implementa la API CoreX para que este Hub pueda crear tenants y leer sus estadísticas. La especificación completa está en docs/API_SAAS.md; el kit listo para pegar en un proyecto django-tenants está en sdk/corex_agent/.

Dos sentidos: el Hub consulta al SaaS (pull, con el API token de cada servicio) y el SaaS empuja métricas al Hub (push, con el token de ingesta). Podés usar uno o ambos; si llegan los dos para el mismo día, se fusionan.

Hub → SaaS (lo implementa cada SaaS)

Base: Servicio.api_url · Header Authorization: Bearer <api_token> · Timeout {{ timeout }} s

GEThealth/Estado y versión
GETtenants/Lista (para importar)
POSTtenants/Crear tenant (idempotente)
GETtenants/<schema>/Detalle
GETtenants/<schema>/metricas/?desde=&hasta=Serie diaria
POSTtenants/<schema>/suspender/Bloquear acceso
POSTtenants/<schema>/reactivar/Desbloquear
POSTtenants/<schema>/plan/Nuevos límites

SaaS → Hub (ya implementado acá)

Base: {{ hub_url }}/api/v1/ · Header Authorization: Bearer <ingest_token>

GETping/Probar el token
POSTmetricas/Snapshots diarios (hasta 500 por llamada)
POSTtenants/estado/Aviso de cambio de estado
 
curl -X POST {{ hub_url }}/api/v1/metricas/ \
  -H "Authorization: Bearer $COREX_INGEST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"items": [{"tenant": "gestmitienda", "fecha": "2026-11-10",
       "metricas": {"ventas_cantidad": 37, "ventas_monto": 412500,
                    "comprobantes_arca": 35, "usuarios": 4}}]}'

Tipos de métrica

contador: lo que pasó ese día (ventas, turnos, comprobantes). El consumo del mes es la suma desde el día 1 y se compara con el límite mensual del plan.

nivel: el valor en ese momento (usuarios, productos, MB usados). El consumo es el último valor recibido.

Los valores deben ser numéricos; las claves que no estén definidas en el SaaS igual se guardan y se muestran en el panel dev para que las definas.

Probar sin tocar los SaaS

Hay un SaaS simulado en sdk/mock_saas.py que implementa todo el contrato con datos aleatorios:

python sdk/mock_saas.py --puerto 9001 --token prueba123
# Luego, en el servicio: API URL = http://127.0.0.1:9001/corex/v1/  ·  API token = prueba123
